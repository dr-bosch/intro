# A Civic Proposition

Democracy is more than representation.

It is participation in public reason.

Citizens should not merely receive decisions.

They should be able to inspect the reasoning from which those decisions arise.

The analytical methods available inside governments, universities, multinational corporations, and international organizations should increasingly become part of the civic commons.

Reasoning is public infrastructure.

---

# The Repository

This is not an archive.

It is not a website.

It is not simply documentation.

It is an attempt to represent governance as a semantic system whose reasoning can be inspected, questioned, extended, and improved.

Every document is part of a graph.

Every graph is part of a conversation.

---

# First Principles

This project begins with a simple assumption.

Knowledge creates obligations.

When knowledge enters a public institution, something changes.

A submission is no longer merely a document.

It becomes part of a relationship.

That relationship carries responsibilities.

Not only legal responsibilities.

Constitutional responsibilities.

Administrative responsibilities.

Professional responsibilities.

Ethical responsibilities.

Ultimately, democratic responsibilities.

# The Graph

Every node answers six questions.

> **Who acted?**

> **Under what authority?**

> **Subject to what duty?**

> **Supported by what evidence?**

> **Through what process?**

> **Toward what public purpose?**

The graph therefore represents both institutional behaviour and institutional obligation.

---

# Ethics as Structure

This repository does not treat ethics as commentary.

Ethics is part of the architecture.

A duty is not merely a legal citation.

It is a semantic relationship.

A right is not merely an entitlement.

It creates reciprocal obligations.

Authority exists only together with accountability.

Evidence creates responsibilities.

Knowledge changes the state of the system.

Governance is therefore understood as the continual reconciliation of facts with obligations.

---

# Why Operations Research?

Operations Research asks remarkably simple questions.

What should be done?

According to what objective?

Using which constraints?

At what cost?

Under what uncertainty?

Those same questions apply to public institutions.

Governance is a decision system.

Democracy deserves to understand how that system reasons.

---

# The Common Good

Analytical capacity is a public good.

Once developed, it benefits everyone.

Its use by one citizen does not diminish its availability to another.

Its value grows through participation rather than depletion, making it part of the shared civic infrastructure that supports competent public administration. The repository explores this idea alongside the constitutional conception of the common good and the role of citizen-contributed knowledge in strengthening that shared capacity. :contentReference[oaicite:0]{index=0}

Knowledge withheld from public reasoning is not merely unused.

It is socially unrealized.

# For Technical Readers

Think of this repository as an executable ontology.

Not because governments are software.

But because public institutions continuously transform:

Actors

into Processes,

Processes into Records,

Records into Decisions,

Decisions into Precedent,

and Precedent into the conditions under which future citizens live.

The objective is to make those transformations visible.
